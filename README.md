# 구현할 기능 목록

* 입력 기능
    * [ ] 자동차 이름 입력
    * [ ] 시도할 횟수 입력
---
* 출력 기능
    * [ ] 시작 메세지 출력
    * [ ] 시도 횟수 질문 출력
    * [ ] 실행 결과 출력
    * [ ] 최종 우승자 출력
---
* 비즈니스 로직 기능
    * [ ] 자동차 이름 부여
    * [ ] 자동차 이름 구분(콤마 기준)
    * [ ] 전진 조건 인식
    * [ ] 자동차 전진
    * [ ] 자동차 멈춤
    * [ ] 우승자 계산
    * [ ] 우승자 여러명일 경우 쉼표 구분
---
* 검증 기능
    * 사용자가 잘못된 값 입력 시 `IllegalArgumentException`을 발생
        * [ ] 자동차 이름 쉼표(,) 구분 검증
        * [ ] 이름 입력은 영어만 가능하도록 문자 검증
        * [ ] 이름 5글자 이하 검증
        * [ ] 시도 횟수 0인 또는 음수 검증
        * [ ] 시도 횟수 int값 오버플로우 검증
        * [ ] 시도 횟수 입력 시 숫자 아닌 값 입력에 대한 검증
