# 구현할 기능 목록

* 입력 기능
    * [x] 자동차 이름 입력
    * [x] 시도할 횟수 입력
---
* 출력 기능
    * [x] 시작 메세지 출력
    * [x] 시도 횟수 질문 출력
    * [x] 실행 결과 출력
    * [x] 최종 우승자 출력
---
* 비즈니스 로직 기능
    * [x] 자동차 이름 부여
    * [x] 자동차 이름 구분(콤마 기준)
    * [x] 전진 조건 인식
    * [x] 자동차 전진
    * [x] 자동차 멈춤
    * [x] 우승자 계산
    * [x] 우승자 여러명일 경우 쉼표 구분
---
* 검증 기능
    * 사용자가 잘못된 값 입력 시 `IllegalArgumentException`을 발생
        * [x] 자동차 이름 입력 양식 검증
        * [x] 이름 입력은 영어만 가능하도록 문자 검증
        * [x] 이름 5글자 이하 검증
        * [x] 같은 이름 불가능 검증
        * [x] 시도 횟수는 양수만 가능하도록 검증
        * [x] 시도 횟수 입력 시 숫자 아닌 값 입력에 대한 검증
---  
* [x] 돌아가는 쓰레기 구현
